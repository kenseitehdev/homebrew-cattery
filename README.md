# Neo-Bell Laboratories Homebrew tap

This tap provides macOS Casks for laser-ptr, Kitty Litter, and milkmaid, plus a source Formula for Catscan.

After publishing this tap and the matching GitHub release assets, install with:

```sh
brew tap kenseitehdev/cattery
brew install --cask laser-ptr
brew install --cask kitty-litter
brew install --cask milkmaid
brew install catscan
```

Note: the current app bundles are ad-hoc signed and are not notarized. macOS Gatekeeper may require the user to approve opening them in Privacy & Security.
